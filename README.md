# 🚀 VenturePilot AI

AI-powered startup validation platform that helps aspiring entrepreneurs evaluate startup ideas using Large Language Models (LLMs).

## 📌 Problem Statement

Many aspiring founders have innovative startup ideas but struggle to validate them before investing significant time, effort, and resources. VenturePilot AI helps users assess their startup concepts by generating market insights, user personas, risks, MVP recommendations, and business strategies.

## ✨ Features

* Startup Idea Validation
* AI-Generated User Personas
* Market Opportunity Analysis
* Risk Assessment
* MVP Feature Recommendations
* Revenue Model Suggestions
* Startup Readiness Scoring
* Interactive Web Interface

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/Gnanaashritha/venturepilot-ai.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Create a `.env` file

```env
OPENROUTER_API_KEY=YOUR_API_KEY
```

4. Run the application

```bash
streamlit run app.py
```
